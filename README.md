# Clock faces

Ambient, full-screen clock face experiments, inspired by timeface.co.

## Faces

| # | Face | What it does |
|---|------|--------------|
| 01 | [Weather](weather/) | Time and date over a painted gouache sky that follows the live weather where you are: clouds, rain, snow, storms and fog, with dawn, day, dusk and night palettes. |

## Running a face

Open the face's `index.html` in a browser and allow location when asked. Location is only used to look up the weather; it is never shown on screen. Without it, the face shows a neutral grey sky.

Weather data: [Open-Meteo](https://open-meteo.com/).

Location needs a secure page (`https://` or a local file). Some embedded viewers block it.
